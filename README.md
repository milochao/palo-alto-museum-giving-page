# Palo Alto Museum Giving Page

A standalone, people-first giving-page prototype for the Palo Alto Museum.

## Preview

Open `index.html` in a browser. The page is self-contained and uses bundled assets; it does not need a build step or package installation.

## Status

This is a working concept, not production website copy. Portraits and their captions are FPO. Replace them with identified participants, verified story details, and approved photography before publication.

The giving architecture uses published membership prices, brick prices, space-naming threshold, and donor-recognition thresholds. Program pricing and any separate philanthropic giving circles still need Museum approval.
